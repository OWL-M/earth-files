# Vendored widgets

Widgets copied from [pop-os/libcosmic](https://github.com/pop-os/libcosmic)
because upstream iced has no equivalent. Phase 1 vendors them unchanged apart
from import paths; Phase 2 ports them to plain iced 0.14.

libcosmic is MPL-2.0 and carries no "Incompatible With Secondary Licenses"
notice, so MPL-2.0 section 3.3 permits distributing these files as part of this
GPL-3.0-only work. Each vendored file keeps its original MPL-2.0 header; do
not relicense it.

`svg.rs` comes from iced rather than libcosmic. iced is
MIT, which is GPL-3.0-compatible; it keeps its own MIT header.

## The fork delta that is not a widget

Phase 3's theme step turned up API that libcosmic's *iced fork* added below the
widget layer, which upstream `iced 0.14` has no counterpart for. None of it is a
vendored widget, so it is recorded here rather than in the table above.

### Blanket conversions: `src/ui/convert.rs`

Six `From` impls the fork added to `iced_core` itself. Both the trait and the
type are foreign to this crate, so the orphan rule forbids implementing
`From` here; they are extension traits instead, and `.into()` becomes `.to_color()`,
`.to_radius()`, `.to_padding()`, `.to_pixels()`, `.to_background()`,
`.to_length()` or `.to_srgba()`. Every body is copied from the fork, including
the array element order for `Radius` and `Padding`, where getting it wrong
would rotate corners rather than fail to compile.
